# CHANGELOG

Please follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- Add the initial fractional indexing implementation and public API.
- Add random and sequential policies for generating indexes before or after
  existing values.
- Add hexadecimal formatting with `Fracindex::to_hex` and the `Debug`
  implementation.

### Changed

- Use the sequential policy by default in `Fracindex::new_before` and
  `Fracindex::new_after`, with explicit policy selection available through the
  new `new_before_with_policy` and `new_after_with_policy` methods.
- Encode fractional indexes as big-endian `u32` components and reserve a gap of
  256 between values generated by the sequential policy.
- Use midpoint allocation near component boundaries for the sequential policy
  to delay fractional index growth.
